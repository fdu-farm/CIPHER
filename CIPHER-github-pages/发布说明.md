# CIPHER 论文主页

已根据提供的 BrReMark 截图制作。内容来自 2607.02596v1.pdf，使用原论文三张图。

## 发布到 fdu-farm/CIPHER

1. 解压后，将整个 docs 文件夹上传到 fdu-farm/CIPHER 仓库的 main 分支根目录。不要覆盖现有源码文件。
2. 打开 https://github.com/fdu-farm/CIPHER/settings/pages
3. 在 Build and deployment 下，将 Source 设为 Deploy from a branch。
4. Branch 选择 main，文件夹选择 /docs，点击 Save。
5. 等待 GitHub Pages 部署完成，页面应显示网站地址 https://fdu-farm.github.io/CIPHER/ 。首次部署可能需要几分钟；以仓库 Actions 和 Pages 页面的成功状态为准。

## 页面内容

- 居中论文标题、作者与单位，Paper / arXiv / Code 按钮
- Abstract
- Method：原论文框架图、因果图和四条路径说明
- Main Results：原始实验图和关键结果
- Citation：BibTeX 及复制功能
- 手机适配、键盘焦点、图片替代文本

## 修改内容

- docs/index.html：论文文字和链接
- docs/styles.css：排版、颜色和手机适配
- docs/script.js：引用复制
- docs/assets/：从论文中提取的三张原图

页面为纯静态文件，无需安装依赖。双击 docs/index.html 可以本地打开；剪贴板功能在正式 HTTPS 页面使用，若本地浏览器不允许自动复制，会选中引用供手动复制。
